# Drag a variable

Every example is parametric: the numbers it is written in are variables, each
with a slider in the **Variables** view.

- In the Halbach rings, drag `n`: both rings rebuild, twenty-four magnets from
  one number.
- A value can be an expression, such as `360 / n`, and a typed unit is
  understood: `15 mm`, `800 mT`.
- Above the sliders, **compact** and **wide** are variants: saved sets of
  values, a click each. **Save as Variant…** keeps the values you have now.
