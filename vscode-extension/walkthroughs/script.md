# Switch to code and back

**Edit Python Script** opens the scene as a magpylib function: its parameters
are the variables, its body the steps that built the objects. Change a line and
save the tab, and the scene follows. A script that fails leaves the scene as it
was.

**Export as Python Script…** writes plain magpylib that anyone can run, without
the studio. **Import Python Script…** goes the other way: it runs a magpylib
script and opens its scene here.
